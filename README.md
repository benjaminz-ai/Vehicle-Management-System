# Vehicle Management System

A modern web-based fleet vehicle management application built with Next.js.

## Getting Started

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS
- dnd-kit (drag and drop)
- lucide-react (icons)

## Notes

- All data is stored in client-side state only. Refreshing the page resets to dummy data.
- No backend or authentication is included.
